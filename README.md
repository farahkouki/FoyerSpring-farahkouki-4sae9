## 📖 Project Overview

FoyerSpring is a comprehensive student housing management system developed with Spring Boot, designed to modernize and streamline university residence operations.

## 🌟 Key Features

- 🏢 **Foyer Management** - Complete CRUD operations for student residences
- 🧑‍🎓 **Student Allocation** - Automated room assignment system
- 📅 **Reservation System** - Academic year-based booking management
- 📊 **Reporting Module** - Occupancy statistics and analytics
- 🔐 **Secure Access** - Role-based authentication

## 🛠️ Technical Stack

| Layer           | Technology           |
|-----------------|----------------------|
| **Framework**   | Spring Boot 3.1      |
| **Database**    | MySQL 8              |
| **ORM**         | Hibernate/JPA        |
| **Build Tool**  | Maven                |
| **Utilities**   | Lombok, MapStruct    |
